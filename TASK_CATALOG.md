## First vertical slice: Prep me for 2015+ IRS installation

This is the first end-to-end workflow because it exercises the product's core
claims: authoritative manual guidance, supporting option documents, structured
torque references, sequence dependencies, current-Mk5 forum caveats, and exact
PDF-page navigation.

### Fast briefing target

Return a concise readiness decision, primary manual pages, required delivered-part
checks, tool/assistance needs, non-negotiable stop conditions, relevant structured
torque rows, and source links.

### Deep briefing target

Use the supplied template to provide the manual baseline, exact-project
applicability, documented gaps, labeled field lessons, supplemental hold points,
garage checklist, durable artifact links, and residual uncertainty. Do not repeat
an adequate manual procedure.

### Initial task controls

- Do not authorize drilling, machining, forcing, or modifying an unexplained IRS
  fitment issue.
- Treat mismatched delivered hardware as a Factory Five clarification/replacement
  issue.
- Keep the center section supported and confirm all four mounts/alignment before
  final retention.
- Present forum techniques only as labeled community context.
