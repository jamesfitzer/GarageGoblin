# Source Drop Folder

Place incoming manuals, torque sheets, briefing templates, build specifications, decision registers, and curated forum material here.

This folder is an intake area. Files will not be renamed, moved, modified, or ingested until explicitly reviewed and approved.

When adding a source, keep its original filename where possible and include its revision/version in the filename or an accompanying note. For forum material, a text or Markdown file containing the thread URL, title, and a short relevance note is sufficient.
