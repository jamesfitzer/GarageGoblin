# Garage Goblin Source Catalog

This catalog describes the current intake only. It does not authorize a file move,
rename, upload, or ingestion. "Initial ingestion" means the first local retrieval
proof, not public delivery.

## Classification key

- **Controlling:** governs when applicable.
- **Applicable secondary:** supports a selected Mk5 option but cannot override the
  Mk5 manual.
- **Conditional/reference:** potentially useful, but its Mk5 applicability must be
  confirmed before use in a briefing.
- **Curated community:** contextual evidence only; never official instruction.
- **Owner-private:** personal or exact-build data, excluded from demo retrieval and
  delivery unless separately sanitized and approved.
